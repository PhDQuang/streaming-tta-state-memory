## Reasons to reject the scientific claim at present

### 1. The likely novelty is an empirical finding that does not exist yet

The protected claim is a combination of matched preformed history batches, common terminal observations, a disjoint common suffix and explicit state interventions. That is a reasonable experimental design. It is not by itself a surprising scientific result. Noncommuting updates, stateful optimizers, order dependence, recurring-shift collapse and reset benefits already have extensive precedents in the reviewed literature.

The strongest threats remain RDumb, PeTTA, POEM, ASR, OATTA, TTABC and AttenDence v1. RDumb already motivates continual-shift benchmarking and periodic source resets; POEM already addresses repeated original images across corrupted copies; ASR makes reset timing/location central; TTABC already makes controlled comparison of update targets a research contribution; AttenDence v1 explicitly discusses retaining optimizer memory after parameter resets. The project must not repackage any of these as its discovery. The current novelty analysis correctly acknowledges these overlaps. [RDumb proceedings](https://proceedings.neurips.cc/paper_files/paper/2023/file/7d640f377893fc5f22b5610e175ef7c3-Paper-Conference.pdf), [POEM proceedings](https://proceedings.neurips.cc/paper_files/paper/2024/hash/9b35a0a20d617dc68ae98a7a57df2f51-Abstract-Conference.html), [ASR](https://openreview.net/forum?id=0JayjvOKxt), [TTABC v2](https://arxiv.org/html/2606.14299v2), [AttenDence v1](https://arxiv.org/html/2511.18925v1).

A bounded search that did not find the exact full combination cannot establish a strong first claim. The submission needs a replicable and useful finding: for example, a practically consequential persistence regime, a state-interaction pattern that changes a defensible scientific understanding, or a precise negative result that overturns an established expectation under credible settings. The tiny upstream SAM state-serialization demonstration is good implementation auditing; it is not that finding.

**Required remedy:** complete prespecified benchmark confirmation and replication, retain every negative result, and write the final contribution around what those experiments actually establish. If only W=0 order sensitivity or a wrapper-checkpoint defect survives, narrow the deliverable to an engineering report or protocol note.

### 2. State-reset responses do not uniquely identify stored information or a natural mechanism

The eight P/O/A cells give well-defined intervention response contrasts. Resetting parameters to the source while retaining a late optimizer produces a hybrid state that may never arise naturally. Its behavior can reflect compatibility between parameters and optimizer, distance from the source, or new dynamics induced on Q. The current proposal explicitly recognizes this limitation; the manuscript must preserve it.

Q is itself adaptive. A difference in mean Q predictions combines the initial junction state with how subsequent common observations amplify, reduce or transform that difference. A parameter-reset first-batch equality check is a valuable implication of pre-update scoring, but does not show that all later discrepancy was uniquely stored in momentum. Likewise, an auxiliary reset changes SAR recovery timing; a disappearance of discrepancy after reset could arise because both paths collapse or repeatedly return to the source.

**Required remedy:** for an optimizer-mechanism claim, promote frozen-Q readout, per-batch divergence, momentum 0 versus .9, and complete automatic-reset traces from optional to required controls. Component swaps between AB/BA states can strengthen the analysis when scientifically meaningful. Present factorial contrasts as responses to the declared interventions, not an additive percentage attribution of memory. These controls can be implemented free; convincing benchmark execution remains future work.

### 3. Baseline coverage and correction effects are unresolved

The current evaluated methods are source, current-batch normalization, Tent and `sar_complete`. Published-algorithm fidelity is checked on eight ordinary non-recovery steps, and that is appropriately scoped in the baseline document. It does not establish behavioral equivalence during recovery, empty filtering or numerical failures, precisely where the implementation intentionally differs from its reference.

Stage A's frequent SAR recovery makes this limitation concrete. A purported universal optimizer-memory finding based only on the corrected implementation could actually depend on the correction. No image trajectory comparison between faithful pinned SAR and `sar_complete` has yet been shown. Untrained ResNet/ViT CPU tests prove that gradient/replay paths execute; they do not validate source checkpoint accuracy, preprocessing, adaptation hyperparameters, CUDA behavior, or published results.

**Required remedy:** include and clearly label faithful-versus-corrected SAR under matched image streams before attributing benchmark effects to the published algorithm. Implement a recent reset baseline such as ASR and at least one persistent/teacher/memory method with a complete state inventory. EATA is conditional on an appropriate, disclosed Fisher/source-data protocol. Establish credible source and baseline performance on exactly the chosen checkpoint/preprocessing before interpreting disagreement. No claimed state-of-the-art ranking is supported now.

### 4. Confirmation remains insufficiently locked and potentially underpowered

At first inspection, H1 refers to a "primary continual-adaptation setting" without naming the exact primary adapter/backbone. H2 refers to "at least one prespecified optimizer/auxiliary reset contrast" without enumerating the actual confirmatory family. The list of available methods and eight intervention cells is not equivalent to choosing a primary contrast. This leaves room to choose the winning condition after seeing pilot or confirmation outcomes.

The three pilot panels are appropriate for debugging and rough timing but provide a poor estimate of heterogeneous panel variance. The proposed 24 disjoint confirmation panels solve a genuine base-ID budget issue; they do not guarantee power for the 1-point persistence threshold or 0.5-point state contrast. A fixed 50k-image benchmark and only three corruption scenarios support design-conditional statements. Reusing scenarios within a panel cannot create more independent evidence. The current analysis correctly averages those repetitions and does not treat the three Stage A source seeds as three new image panels.

**Required remedy:** name the exact primary algorithm, backbone, mixture/orientation of domains, W, suffix scoring mode, effect family and simultaneous interval procedure before examining confirmation outcomes. Freeze how pilot variance can alter N and define what happens when the available identity budget cannot deliver the target precision. Report inconclusive intervals honestly. Do not select hyperparameters, severities, history lengths or methods for confirmation because they produced the largest pilot effect.

### 5. External validity and the meaning of disagreement are still open

AB/BA block reversal is a deliberate, strong temporal perturbation. It demonstrates controlled path dependence if an effect exists; it is not a model of natural chronology. A W=16 result at batch size 32 is persistence after 512 recent images, not an intrinsic time constant. History length, update rate, batch size, automatic resets and Q adaptation all change that scale. Additional corruption families and a natural-domain replication are currently plans.

Argmax disagreement can be dominated by near ties and need not change expected error or calibration. Signed error differences can cancel across oriented scenarios; absolute finite-panel gaps have sampling bias. The current proposal and analysis correctly distinguish these metrics. The tiny Stage A disagreement must not be magnified into a useful robustness effect by reporting only a logarithmic or tightly cropped axis.

**Required remedy:** report per-panel and per-scenario results, raw probability/NLL effects, error direction, source-relative performance and failure/reset traces. Require a second architecture and dataset for the intended broad claim. Treat natural-domain streams and other history structures as explicit replication or scope limits. Do not claim mCE from the three-corruption severity-5 panel.
